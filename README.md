# 示波器AI助手成果与佐证

本仓库整理示波器安卓语音助手源码、领域ASR微调方法与固定词典、配对评测工具和记录、实机截图、使用反馈及旧工程Git历史。

- `current_android_1.5.1`：安卓应用源码及工程说明。
- `research_and_evaluation`：研究ASR方法、固定词典和5620条配对评测记录。
- `evidence`：实机截图、使用反馈、仓库记录和完整Git历史文件。
- [佐证材料PDF](evidence/03_佐证材料.pdf)：整理后的反馈、截图、提交记录和评测结果。
- [技术报告PDF](evidence/02_技术报告.pdf)：作品方案、训练方法、安卓实现及资源清单。

仓库已公开，可直接访问，无需账号授权。模型权重、APK、签名密钥及访问凭据不在本仓库内，运行资源按工程说明配置。研究评测与端侧4-gram配置分别记录。
